# 手机上手（零基础）

> 这份文档假设你**没有任何安卓开发经验**，也不想碰命令行。
> 只需要手机 +（可选）一根数据线。

## 1. 把 APK 弄到手机上

APK 就在这台电脑上的这个位置（在文件夹地址栏粘进去就能打开）：

```
D:\Code\DeepSeek\alarm-clock\android\app\build\outputs\apk\debug\app-debug.apk
```

文件名是 `app-debug.apk`，约 20 MB。三种传法，挑一个：

### 办法 A：数据线（最稳，推荐）

1. 用数据线把手机插到电脑上
2. 手机屏幕上会弹出「USB 用途」，选 **传输文件 / MTP**（不选"仅充电"）
3. 电脑上打开「此电脑」，会多出一个手机图标，点进去
4. 把 `app-debug.apk` 复制到手机的 **Download（下载）** 文件夹
5. 拔线，在手机上打开「文件管理」→「下载」，点那个 apk

### 办法 B：微信 / QQ 文件传输助手

1. 电脑上打开微信，找到「文件传输助手」对话框
2. 把 `app-debug.apk` 拖进去发送
3. 手机上打开这条消息，点文件 → 右上角「…」→「用其他应用打开」→ 安装

> ⚠️ 微信有时会把 apk 改名成 `app-debug.apk.1` 之类。如果手机上点不开，
> 先用「文件管理」把它重命名，把结尾多余的 `.1` 去掉。

### 办法 C：网盘

上传到自己的网盘，手机端 App 里下载，再点开安装。同样注意不要被改后缀。

## 2. 安装（小米 / HyperOS 会拦一下，属正常）

点开那个 apk 之后，按屏幕提示走。小米特有的两种情况：

| 屏幕上出现什么 | 怎么处理 |
|---|---|
| 「未知来源应用」/「禁止安装未知应用」 | 点「设置」→ 打开「允许来自此来源的应用」→ 返回 → 继续安装 |
| 「纯净模式」拦截、或提示「该应用存在风险/未经安全检测」 | 两个办法任选：<br>① 点提示里的「仍然安装」/「继续安装」<br>② 彻底关掉纯净模式：**设置 → 应用设置 → 应用管理 →（右上角 ⚙ 或 ⋮）→ 纯净模式 → 关闭** |
| 「Play 保护机制」警告 | 点「仍要安装」 |

装完桌面上会出现一个叫 **「闹钟坞」** 的图标（蓝色小闹钟）。

> 这是**调试版（debug）**，功能是完整的、可以日常用；只是体积比正式版略大，属于正常现象。

## 3. 用眼睛验收「权限跳转」（档 2，不需要任何工具）

这一步就一件事：**看看点「去设置」之后，手机跳到的是不是对的那个页面。**

### 怎么做

1. 打开「闹钟坞」
2. 右上角（或左上角）点 **设置** → 点 **权限体检**
3. 你会看到 7 行，每行右边有「去设置 ›」。**逐行点一遍。**
4. 每点一行，只记三件事：

   | 记什么 | 具体 |
   |---|---|
   | ① 跳到哪个页面 | 拍张照最省事 |
   | ② 那个页面上能看到对应的开关吗 | 能 / 不能 |
   | ③ 返回应用后，页面**底部**有没有出现一条**黄色**的提示 | 有 / 没有 |

### 我最想知道的两行

| 行 | 「命中」长什么样 | 「没命中」长什么样 |
|---|---|---|
| **自启动** | 跳到小米的「**自启动管理**」页面，上面直接有一个开关 | 跳到通用的「**应用信息**」页面（上面有「卸载 / 强行停止 / 权限 / 存储」这些），页面底部还会出现那条黄色提示 |
| **后台弹出界面** | 跳到小米的「**应用权限管理**」或「其他权限」页面，里面能看到「后台弹出界面」这一栏 | 同上，落在「应用信息」 |

**另外请特别看一眼有没有哪一行显示成「不适用」（灰色横杠）。**
在小米手机上，**「自启动」「后台弹出界面」「锁屏显示」这三行应该都是可以点的**（显示 ✓ 或 ✕）。
如果它们显示成「不适用」，说明我的程序没认出这是小米系统 —— **这是我最需要知道的一种情况**，请务必告诉我。

### 怎么把结果给我

文字就够，比如：

```
自启动：跳到了「自启动管理」页面，有开关，没有黄条 —— 命中
后台弹出界面：跳到了「应用信息」页面（有卸载/强行停止），底部出现黄条 —— 没命中
锁屏显示：显示「不适用」（灰的，点不动）
```

有截图更好。截图就是普通的手机截图（电源键 + 音量减），不用做任何处理。

## 4. 然后就可以正常用了

装好之后，先花半分钟把该开的开关开掉，否则闹钟到点可能不响：

1. **通知** —— 体检页点「通知」，会弹一个系统框，选「允许」
   （这个开关很重要：没有它，**锁屏时闹钟不会自动弹出界面**）
2. **精确闹钟 / 全屏通知** —— 一般已经是 ✓，不用管
3. **电池无限制** —— 点「去设置」，选「无限制 / 不优化」
4. **自启动、后台弹出界面** —— 都打开
5. **⚠️ 别忘了给它在最近任务里「加锁」**

   在手机的最近任务（多任务）界面，找到「闹钟坞」那张卡片，
   上面应该有一个**锁头图标**，点一下变成锁住状态。

   为什么必须做：如果你手动「结束运行」它、或者把它从后台彻底划掉，
   **任何第三方闹钟都无法再被唤醒**——这不是这个应用的缺陷，是安卓的系统限制。
   加锁就是告诉系统「别清它」。

应用**第一次打开时也会弹出一次引导卡片**把上面这些讲一遍，照着点「去体检」就行。

## 4.5 闹钟响了但停不下来，怎么办

（这一节是实测踩出来的，写在这里免得以后再慌。）

**先记住三件事**：

- **下拉通知栏**，最上面那条「闹钟响铃」通知里有一个「**关闭**」按钮 —— 这是响铃页之外的第二个关闭入口。
- **什么都不做，10 分钟后会自动停**（你所有闹钟的「响铃超时」都是 10 分钟）。
- **按音量键不是关闭，是「贪睡」** —— 它会安静一会儿，然后 10 分钟后**再响一次**（最多 3 次）。
  在设置里可以把「音量键」改成「关闭」。

**已经修好的三个坑**（这份 APK 里都修了）：

| 原来的毛病 | 现在 |
|---|---|
| 响铃页在解锁状态下不会自己弹到最前，而它又被排除在「最近任务」之外 —— **页面存在，但你怎么点都到不了** | **打开应用就直接进响铃页**；响铃页也不再被排除在最近任务外 |
| 在响铃页按**返回键**会把页面推走，然后就回不来了 | 返回键**不会**离开响铃页（会提示「请选择贪睡或关闭」）。想离开就按 Home |
| 把正在响的那条闹钟**从列表删掉**，声音**不会停** | 删掉或关掉正在响的那条，声音**立刻停** |

**所以现在最自然的做法**：闹钟响了 → 打开应用（或点通知）→ 在页面上选「关闭」或「贪睡」。

## 5. 不想反复装机怎么办（迭代时怎么分工）

装一次 APK 要传文件、点安装、应用还会重启 —— 界面改动频繁时确实烦。**好消息是绝大多数改动根本不需要装机。**

### 5.1 三种"在电脑上看"的环境，按用途选

| 环境 | 怎么看 | 适合看什么 | **看不出什么** |
|---|---|---|---|
| **浏览器预览**（最快） | 我在这台电脑上运行 `npm run web:dev`，你用浏览器打开 **http://127.0.0.1:5173/** | 布局、配色、文案、页面跳转、表单校验。改一行立刻自动刷新，**零安装** | 触摸手势、原生能力（权限页/响铃/数据库）—— 它用的是假数据 |
| **模拟器**（最像手机） | 让模拟器**带窗口**启动，你在电脑屏幕上直接点它（我可以帮你启动） | 真机上的绝大部分行为：真数据库、真权限页、真响铃链路 | HyperOS 特有的后台管控；**鼠标没有"甩动惯性"**，所以滚轮那种手感拖不出来（要真手势我用 `input swipe` 帮你注入） |
| **真机** | 装 APK（就是现在这条路） | HyperOS 后台管控、MIUI 私有权限页、震动、听感 —— **只有真机能验的** | 没有 |

**分工建议**：界面/交互/文案的反复打磨 → 浏览器或模拟器；只有 HyperOS 特有的行为，或者你想确认"手感"时，才装一次真机。

### 5.2 真机上也能免重装（只对网页改动有效）

这个应用是"网页装在 APK 里"。Capacitor 支持让 WebView 改从**电脑上的开发服务器**加载，这样
**改动网页后手机上刷新一次就能看到，完全不用重装**：

```
电脑:  npm run web:dev                       # 起开发服务器（监听 5173）
电脑:  adb reverse tcp:5173 tcp:5173         # 把手机的 localhost:5173 接到电脑上
手机:  重新打开应用                          # 它改成从开发服务器加载
```

代价与前提（都要注意）：

- **只对网页（`web/` 下的东西）有效**；改了 Kotlin（原生）仍然必须重新构建+安装。
- 手机必须**插着数据线**（靠 `adb reverse`），电脑上的开发服务器必须一直开着 —— 一关，应用就白屏。
- **必须要有一份"指向开发服务器"的单独配置**，绝不能混进要交付的 APK：
  否则装到手机上的正式包会去连一个不存在的 localhost，直接白屏。
  所以这件事要做就做成两个配置文件 + 两个 npm 脚本，我不会直接改默认配置。
- 所以我**建议先不做**：现在网页改动的频率已经很低了（滚轮和保存修完之后），
  而且它带来的"配置文件搞混就白屏"的风险，比省下的几次装机更麻烦。

### 5.3 你想自己动手的话，最实用的一步是：让模拟器带窗口

现在模拟器是**无窗口**跑的（只有我能驱动它）。我可以把它重启成**带窗口**的，
这样你在电脑屏幕上就能直接看到整个手机界面、用鼠标点它 —— 看布局和流程足够了。
看完再决定要不要往真机装。

**要的话跟我说一声**，我重启一下（约 1 分钟），并告诉你窗口长什么样、哪些操作点得动。

## 6. 什么时候才需要电脑 + 真机（档 3）

M7 里有几项**必须**用电脑上的 `adb` 才能验，手机上做不到，比如：

- 「应用被系统回收后闹钟还能不能响」（需要电脑敲一条命令模拟"被回收"）
- 改系统时间 / 时区之后的自动重算（需要电脑读系统侧的闹钟注册表来独立核对）

好消息是：**这台电脑已经装好了 adb，你什么都不用安装。**

### 需要你做的准备

**手机上打开 USB 调试**（一次性的）：

1. 设置 → 我的设备 → 全部参数与信息 → **连点「MIUI 版本」7 次**，直到提示"你已处于开发者模式"
2. 返回 → 更多设置 → **开发者选项** → 打开 **USB 调试**
3. 用数据线插到电脑，手机上弹「允许 USB 调试吗？」→ 勾选「一律允许」→ 确定

**电脑上**：告诉我你插好了，我会直接把命令一条条给你（都是复制粘贴，每条我都会写清"看到什么算通过"）。
如果你想自己先看一眼，先跑这两条确认手机认出来了：

```powershell
cd D:\Code\DeepSeek\alarm-clock
. .\tools\env.ps1
adb devices
```

「通过的样子」：输出里能看到一行你手机的型号（**不是** `emulator-5554`）。

完整的命令清单在 [MACHINE-CHECKLIST.md](MACHINE-CHECKLIST.md)，从 §0 开始，每条都写了命令和判读标准。
